# The Pattern: offline research explorer

This is the previously generated fan-facing HTML atlas imported as an immutable presentation snapshot. It embeds only structured numeric/metadata arrays, no EPUBs or novel prose, and uses no network dependencies. Historical browser checks are documented in prior research packages; this import has not yet repeated them in GitHub Actions.

The HTML contains a radial chapter wheel, chapter lexical seams, exact-echo locators, cast coappearance network and distinctive vocabulary. Interpretations are hypotheses, not evidence of literary quality or causation.

Open `index.html` locally or deploy the `explorer/` directory to a static host. This is not proof GitHub Pages is enabled.
