# Attribution, source scope, and rights

**Application code:** MIT license, Pattern Lab independent research implementation. This repository/browser package is not an official Wheel of Time project.

**Pele SVG renderer:** [obsidianmd/pele](https://github.com/obsidianmd/pele), version 1.10.0, © Pele contributors, MIT license; original [license text](vendor/PELE-LICENSE.txt) is included. Pinned distribution originates from the official npm release and was independently package-built by GitHub Actions, not rewritten. The JS bundle checksum is in `MANIFEST.json`.

**Source graph:** produced by the prior verified private Wheel of Time research pipeline and exported as a **public-safe** GraphML schema. Contains no copyrighted novel paragraphs. The original public-safe graph has 6,713 nodes and 30,817 directed edges, including 22,269 *lexical candidate* edges. This graph is a research index, not a licensed canonical Wheel of Time semantic graph.

**Community data sources:**

- [Wheel of Time Wiki: statistical analysis / POV listing](https://wot.fandom.com/wiki/Statistical_analysis). Community-maintained POV metadata and character names. Publisher/rights and community-site reuse requirements remain distinct from this application's MIT code.
- [Wheel of Timelines](https://wheeloftimelines.com/) contributed some curated event, place, timeline, and participant-label data to earlier research; [project GitHub](https://github.com/wheeloftimelines). Individual event interpretation and in-world timing were **not independently adjudicated** in this graph.
- Exact paragraph recurrence source coordinates derived from privately provided EPUBs. **Novel text is not redistributed**.

Labels are presented as source labels: for example, a timeline's `Mat` participant label is not forcibly reconciled with the `Matrim Cauthon` POV-owner label. Direct source links, provenance fields and explicitly unverified candidate statuses remain preserved.

If republishing outside personal research, independently confirm licensing of all upstream metadata and meet any applicable attribution/share-alike requirements, in addition to the MIT requirements for the application and Pele.
