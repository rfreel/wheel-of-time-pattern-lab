# Drawing method

The reference site uses the Pele Mermaid layout library, then custom JavaScript re-renders the shapes with a pen and colored pencils. This release uses the same separation of geometry and drawing without bundling Pele: hand-calibrated quantitative chart geometry, deterministic jitter and crosshatching, and animated Canvas strokes.
