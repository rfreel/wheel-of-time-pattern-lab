# Curated text-free data

chapters.csv: 704 ordered EPUB chapter metadata rows.
pov_segments.csv: 1,379 ordered curated POV segments; one unaligned.
pov_chapter_metrics.csv: derived POV entropy, debuts, switches and coverage; independently reproduced by scripts/analyze_pov.py.

POV word totals are source-specific and do not equal EPUB tokenizer counts. The novel text and source EPUBs are excluded. Historical numerical core remains external and immutable.
